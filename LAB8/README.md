# LAB 8 – LOCAL DNS ATTACK

**Môn học:** Thực hành An toàn Hệ thống Thông tin

## Nội dung thực hành

- Tìm hiểu cơ chế hoạt động của DNS.
- Cấu hình DNS Server bằng BIND9.
- Tìm hiểu DNS Spoofing và DNS Cache Poisoning trong mạng ảo cô lập.
- Sử dụng Wireshark để phân tích gói tin DNS.
- Kiểm tra và khôi phục cấu hình DNS sau thực nghiệm.

## Môi trường

- pfSense
- Ubuntu Server
- Kali Linux
- BIND9
- Wireshark
