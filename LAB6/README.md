# LAB 6 – XÁC THỰC ACTIVE DIRECTORY VÀ CHÍNH SÁCH TRUY CẬP TRÊN pfSense

Môn học: An toàn và Bảo mật Hệ thống Thông tin

## Nội dung thực hành
- Cấu hình pfSense với WAN, MGMT, LAN và DMZ.
- Cấu hình Active Directory và LDAP.
- Thiết lập Captive Portal.
- Tạo Firewall Alias và Schedule.
- Kiểm thử 7 kịch bản chính sách truy cập.
- Phân tích Firewall Log và State Table.

## Môi trường
- VMware Workstation
- pfSense CE
- Windows Server
- Windows 11
- Ubuntu Server
